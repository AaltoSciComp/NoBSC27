FAQ

Questions from attendees will be placed here. You can send questions to Richard or Samantha for now.

Registration

I can only attend part of the time. Is there a discounted registration fee? We unfortunately don’t have the organizer capacity to deal with partial registrations. Maybe later.

If I need to pay for everything, why do I need to know what meals I attend? Can I change later? Despite the above, we would like to minimize food waste. Keep this up to date and we will keep the caterers informed. Small adjustments are probably possible.

Can I attend online? This event is mainly a networking event, so we are taking our limited time to focus on the in-person part. If we got volunteers to host the online part (we can provide the equipment), then we can consider this for the main talks.
